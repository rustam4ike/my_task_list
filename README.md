# 📝 Мои задачи (My Task)

Простое и удобное мобильное приложение для управления задачами, написанное на **Flutter**.  
Работает полностью офлайн, сохраняет данные в локальной базе **SQLite**, не содержит рекламы и подписок.

---

## ✨ Возможности

- ➕ **Добавление задач** — через текстовое поле или клавишу Enter.
- 📋 **Просмотр списка** — эффективный `ListView.builder`.
- ✏️ **Редактирование** — изменение названия через диалоговое окно.
- 🗑️ **Удаление** — с подтверждением через `AlertDialog`.
- ✅ **Отметка о выполнении** — задача зачёркивается, становится серой и уходит вниз списка, с плавной анимацией
- 💾 **Сохранение в SQLite** — данные не теряются при закрытии приложения.
- 📱 **Работает офлайн** — не требует интернета.

## 🧠 Как это работает

Приложение построено по простой слоистой схеме:

1. **Модель `Task`** — хранит `id`, `title`, `isDone`.
2. **`TaskRepository`** — отвечает за создание БД и все CRUD-операции.
3. **`TaskListScreen`** — загружает задачи из репозитория и обновляет интерфейс.
4. **Виджеты** — `TaskInputField`, `TaskItem`, `EditTaskDialog` — отвечают за отображение и взаимодействие.

**Поток данных:**  
Пользователь вводит задачу → `TaskListScreen` вызывает `TaskRepository.add()` → данные сохраняются в SQLite → список перезагружается через `getAll()` → UI обновляется через `setState()`.

**Сортировка:** сначала невыполненные, потом выполненные. Внутри каждой группы — новые сверху.
